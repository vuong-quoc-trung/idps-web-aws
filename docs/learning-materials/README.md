## Cách mở

Sau khi clone hoặc pull nhánh `feat/ai-model-training`, mở file HTML bằng trình duyệt trên máy của bạn. Khi xem trên GitHub, tải cả hai file về **cùng một thư mục** để giữ liên kết qua lại; trang GitHub thường hiển thị mã HTML thay vì bài học.

Nội dung, sơ đồ và ví dụ tương tác dùng được offline. Video và tài liệu tham khảo bên ngoài cần Internet. Nút **In / lưu PDF** nằm đầu mỗi sổ tay.
