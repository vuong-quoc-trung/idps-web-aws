# R48 · AWS Cloud Beta

**R48_CLOUD_BETA = PARTIAL**. Student and Security Web are deployed on the existing Singapore staging EC2. The persistent observation path works for the four allowlisted authentication actions with an exact request target. Full application coverage, reliable three-source availability by 1,000 ms on POST login and public firewall enforcement remain open.

## What changed

- Git fetch found the integration branch at `9ae4944` and the Hybrid development branch at the already integrated `798e66a`. No new compatible commits required merging. The R47 Java, Rust and frontend binaries, both databases and their migration versions were reused.
- The updated Student gateway offers a signed loopback leg for exact GET CSRF, GET session identity, POST login and POST logout requests. All four routes exclude query strings; other Student routes retain application routing. NGINX signs method, target, client and request ID and the private egress verifies them and supplies a receipt. Public responses omit both proof headers. The inference mirror sends only dispatch time, request ID, method and target to the existing UID-gated scorer socket. Suricata runs continuously on the two loopback endpoints with 27 loaded alert rules and no inline mode. EVE and Lua share one sensor generation per process.
- The correlator checks method, path, outcome, signature, receipt and transaction identity before writing a metadata-only match. It measures when all sources become available, records late evidence and remembers recently committed status across restart. Its result feeds the existing Rust Hybrid worker. Sensor metadata on this private leg supplies no independently verified enforcement identity. The Security Web view uses the existing authenticated backend and SSE.
- R37 is URI100 HGB, version `r37-hgb-uri100-v1`, with SHA-256 `91fe8bad280f7c103adc3601579e350fccd1e3b0de65d43c062aec5b34e60aff` and frozen threshold `0.7664756774902344`. A valid score strictly above the threshold may produce an advisory alert. The score has research scope. Hybrid still assesses correlation, rule evidence, timing, attribution and existing policy. A late source cannot establish time-valid three-source evidence. The R36 rollback artifact remains available.
- Cgroup v2 retains 1.5 vCPU/6 GiB/no swap/512 tasks for the application slice. R37 uses 0.25 vCPU/768 MiB/64 tasks, Suricata 0.25 vCPU/384 MiB/48, and the correlator 0.10 vCPU/96 MiB/12. The existing EC2 identity, scorer pressure/OOM/disk checks and watchdog run at boot; the Local thermal profile stays in place. Logs have private access, byte safeguards and a five-minute rotation check. Review the scorer's private receipt size before prolonged operation; the current process limit bounds growth and sustained-volume retention remains a follow-up.

## Access and operation

- [Student Web](https://student-dut.duckdns.org/) and [Security Web](https://websentinal.duckdns.org/) use separate `admin` accounts and passwords. An authorized AWS operator can retrieve or rotate the credentials through SSM. Initial credentials are in the root-only `/etc/websentinel-r47/admin-bootstrap.json` on staging. Use the appropriate `student` or `security` entry through a private operator channel.
- In Security Web, use **Audit ứng dụng** for Student Audit and **AI shadow → HTTPS AI R37 / Hybrid** to look up a Student response's `X-Request-Id`. **Cảnh báo** and **Luật phát hiện** show alerts and rules. **Trạng thái hệ thống**, **IP bị chặn** and **Nhật ký thao tác** show service and Prevention state. A blocked-list status of actuator offline is expected on this observe-only deployment.
- The [R48 installer](../security-web/deploy/aws-r48/update.py) keeps the R47 release in place. It requires the R47 host, source revision and gateway SHA. Verify the update archive and each bundled input. The runtime kit consists of `update.py`, `gateway.py`, `correlate.py`, and the five existing helpers/templates listed by `FILES` in the installer. Provide `SHA256SUMS.json` containing those eight files. Stage through SSM, install the Ubuntu NGINX njs module if absent, and use `python3 -B update.py update --bundle <verified-kit>`.
- For rollback, use `sudo python3 -B /opt/websentinel-r48/runtime/update.py rollback --backup /var/backups/websentinel-r48`. This restores the checked gateway and Security environment, disables R48 observer services and restarts the R47 consumers. It preserves application databases and the current release. The root-only snapshot includes the existing release, app environments, gateway and both logical database dumps. Verify TLS and app health after rollback. [EC2 start/stop and SSM operations](AWS_STAGING_OPERATIONS_HANDOFF.md#2-vận-hành-ec2)

At the R45 planning rate, compute is USD 0.1197/hour; this is an estimate before EBS, IPv4, credits or tax. Auto-Stop remains deferred with the R46 dry-run configuration. Stop through the staging EC2 console after use.
